# 山海五侠 · 大荒行纪（网页版）

手机横屏优先的写实国风 2.5D 大世界 RPG：五位角色各五式技能、八片区域、装备掉落/强化、
区域试炼、异兽图鉴与首领重生。直接打开本站即可玩，进度保存在浏览器本机。

- 本仓库是**构建产物**，源码与开发说明见主项目 shanhai-rpg。
- 网页版没有服务器，因此**不提供注册登录与云存档**；进度存在本机，清除浏览器数据会丢失。
  需要账号、跨设备云存档时，用项目里的 server/ 与 build.mjs 部署带数据库的服务端版本。
- 手机建议横屏；电脑可用 WASD 移动、J/空格普攻、1–5 技能、M 地图、B 行囊、Esc 暂停。
